# **App Name**: Kaamko Kura

## Core Features:

- Task Posting & Bidding: Clients can post tasks with descriptions, budgets (in NPR), and deadlines; freelancers can bid or apply for these tasks.
- Role-Based Authentication: Secure login for Clients, Freelancers, and Admins with different access levels.
- Student Verification: Freelancers can verify their student status by uploading necessary documents for admin approval.
- Task Management: Full task lifecycle tracking: Open → Assigned → Completed, with status updates and notifications.
- Khalti Payment Integration: Secure escrow-style transactions via Khalti, including fund release upon task approval, refunds, and dispute resolution.
- Ratings & Reviews: Clients and freelancers can rate each other (1–5 stars) and leave written feedback to build reputation and trust.
- Collaboration Tools: Real-time chat and file sharing for smooth client–freelancer communication.
- Admin Dashboard: Allows admins to verify student status, resolve disputes, moderate tasks, and view analytics.
- Optional AI Features: AI-powered module (future scope) recommends suitable freelancers based on skills and past performance and may suggest fair pricing.

## Style Guidelines:

- Primary color: Vibrant orange (#FF8C00) to evoke energy and dynamism, reflecting Nepal’s landscapes.
- Background color: Light peach (#FFF5E0) for a warm, inviting backdrop.
- Accent color: Soft yellow (#F0E68C) for key elements and calls to action.
- Headline font: ‘Poppins’ – geometric, modern, and precise.
- Body font: ‘PT Sans’ – modern with warmth and readability.
- Icons: Clean, modern icons representing task categories and user actions.
- Responsive Design: Seamless experience across desktop, tablet, and mobile.
- Buttons & Interactive Elements: Use accent color with clear hover/focus states for better UX.
